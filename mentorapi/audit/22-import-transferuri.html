Import Transferuri — POST /api/import/transferuri

TESTAT + MAPAT

Importă transferuri între gestiuni (mișcări interne fără factură). Flow: SetDocsData → TransferuriValide → ImportaTransferuri.

✅ Testat 14 mai 2026 pe firma ERP — transfer NrDoc=99999, 5 buc PIULITA CU FLANSA M6 din MP → CNC. Validate + import OK. Mapare verificată în GET /api/transferuri.

Request body

POST /api/import/transferuri
{
  "lines": [
    "[InfoPachet]",
    "AnLucru=2026",
    "LunaLucru=5",
    "Tipdocument=TRANSFER",
    "TotalTransferuri=1",
    "Logon=Master",
    "",
    "[Transfer_1]",
    "Operatie=A",
    "NrDoc=99999",
    "Data=14.05.2026",
    "GestDest=CNC",
    "TotalArticole=1",
    "",
    "[Items_1]",
    "Item_1=9007767527987;Buc;5;0.17;MP;14.05.2026;"
  ]
}

Secțiunea [Items_N] — linii articole

Format: Item_N=CodArticol;UM;Cantitate;Pret;GestSursa;Data;

Gestiune sursă per item (poz 5) — gestiunea destinație e pe header (GestDest). Identic cu facturi intrare.
