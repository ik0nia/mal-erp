Import Bonuri de Consum — POST /api/import/bonuri-consum

TESTAT + MAPAT

Importă bonuri de consum (consum intern materiale) în WinMentor. Flow: SetDocsData → BonuriConsumValide → ImportaBonuriConsum.

✅ Testat 14 mai 2026 — bon consum NrDoc=99999, 2 buc PIULITA CU FLANSA M6 din MP → consum CNC. Format dedus prin iterare erori (3 iterații): Tipdocument=BON DE CONSUM, secțiune [Bon_1].

Request body

POST /api/import/bonuri-consum
{
  "lines": [
    "[InfoPachet]",
    "AnLucru=2026",
    "LunaLucru=5",
    "Tipdocument=BON DE CONSUM",
    "TotalDocumente=1",
    "TotalBonuri=1",
    "Logon=Master",
    "",
    "[Bon_1]",
    "Operatie=A",
    "NrDoc=99999",
    "Data=14.05.2026",
    "GestConsum=CNC",
    "TotalArticole=1",
    "",
    "[Items_1]",
    "Item_1=9007767527987;Buc;2;0.17;MP;14.05.2026;"
  ]
}

Secțiunea [InfoPachet]

CâmpObligatoriuFormatDescriere
TipdocumentDAstringFix: BON DE CONSUM (nu "BON CONSUM", nu "BONURI DE CONSUM"!)
TotalDocumenteDAintegerNumăr bonuri în pachet
TotalBonuriDAintegerIdem (ambele necesare)
AnLucru / LunaLucru / LogonDA-Standard

Secțiunea [Bon_N]

Atenție: Secțiunea e [Bon_1], nu [BonConsum_1] sau [Document_1]!
CâmpObligatoriuFormatVerificatDescriere
OperatieDAstring✅A = adăugare
NrDocDAinteger✅Număr document
DataDAdd.mm.yyyy✅Data bonului
GestConsumDAstring✅Gestiune destinație consum (ex: CNC)
TotalArticoleDAinteger✅Nr. linii items

Secțiunea [Items_N]

Format: Item_N=CodArticol;UM;Cantitate;Pret;GestSursa;Data;

Identic cu transferuri — gestiunea sursă pe item (poz 5), gestiunea consum în header.
CâmpPozObligatoriuVerificatDescriere
CodArticol1DA✅SKU/EAN
UM2DA✅Unitate măsură
Cantitate3DA✅Cantitate consumată
Pret4DA✅Preț
GestSursa5DA✅Gestiune sursă (de unde se consumă)
Data6NU✅Dată per linie
