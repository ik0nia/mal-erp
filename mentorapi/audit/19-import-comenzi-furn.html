Import Comenzi Furnizori — POST /api/import/comenzi-furnizori

TESTAT + MAPAT

Importă comenzi furnizor în WinMentor. Flow: SetDocsData → ComenziFurnValide → ImportaComenziFurn.

✅ Testat 14 mai 2026 pe firma ERP, luna 5/2026 — 3 comenzi importate (99999, 99998, 99997). Validate + import OK. Mapare câmpuri verificată complet. CodFurnizor testat cu CodExtern, CodFiscal și CodIntern.
Fix critic: SetDocsData necesită SAFEARRAY(BSTR) construit manual via Win32 syscall și pasat prin vtable by-value (16 bytes). IDispatch nu funcționează. ComenziFurnValide/ImportaComenziFurn trecute de la RawQuery (IDispatch) la callMethodInt (vtable).
