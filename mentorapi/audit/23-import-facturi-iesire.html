Import Facturi Ieșire — POST /api/import/facturi-iesire

TESTAT + MAPAT

Importă facturi de ieșire (vânzări) în WinMentor. Flow: SetDocsData → DateValide → ImportaFacturi.

✅ Testat 14 mai 2026 — 2 facturi importate (99999 minim, 99998 cu 2 articole + parametri extra). Parametri opționali verificați: Scadenta ✅, Observatii ✅, TVAInclus ✅, MarcaAgent (acceptat dar nu apare în output), Locatie (acceptat dar nu apare). ValoareFactura calculată automat de WinMentor (cu TVA).

Request body

POST /api/import/facturi-iesire
{
  "lines": [
    "[InfoPachet]",
    "AnLucru=2026",
    "LunaLucru=5",
    "Tipdocument=FACTURA IESIRE",
    "TotalFacturi=1",
    "Logon=Master",
    "",
    "[Factura_1]",
    "Operatie=A",
    "NrDoc=99999",
    "SimbolCarnet=MAL",
    "Data=14.05.2026",
    "CodClient=728018497",
    "Moneda=LEI",
    "TotalArticole=1",
    "",
    "[Items_1]",
    "Item_1=9007767510699;BUC;4;45.45;MP;"
  ]
}

Secțiunea [InfoPachet]

CâmpObligatoriuFormatDescriere
TipdocumentDAstringFix: FACTURA IESIRE (eroare 102 dacă lipsește)
TotalFacturiDAintegerNumăr facturi în pachet
AnLucru / LunaLucru / LogonDA-Standard

CâmpObligatoriuFormatVerificatDescriere

Secțiunea [Items_N] — linii articole

Format: Item_N=CodArticol;UM;Cantitate;Pret;Gestiune;

Diferență față de facturi intrare/comenzi: Doar 5 câmpuri per item (fără discount, fără dată). Discount pe poz 5 dă eroare 311 + necesită cont discount în constante WinMentor.
CâmpPozObligatoriuVerificatDescriere
CodArticol1DA✅ → [3]SKU/EAN
UM2DA✅ → [6]Unitate măsură
Cantitate3DA✅ → [5]Cantitate vândută
Pret4DA✅ → [7]Preț vânzare unitar
GestiuneDAstring✅Simbol gestiune sursă (eroare 301 dacă invalid)
