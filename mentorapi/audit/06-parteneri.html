Parteneri — GET /api/parteneri

TESTAT + MAPAT

Testat: 11.447 parteneri pe firma ERP. Câmpuri cu "~" conțin valori multiple separate prin tildă (sedii multiple).

POST /api/parteneri/add — AdaugaPartener

Adaugă un partener nou în WinMentor. Acceptă JSON structurat cu 35 câmpuri. Returnează result: 1 la succes.

✅ Testat 14 mai 2026 pe firma ERP — partener TESTAPI001 creat cu succes. Mapare câmpuri verificată complet: id, denumire, codFiscal, localitate, adresa, telefon, persoaneContact, simbolClasa (→ DenClasa auto), idAgent (→ NumeAgent auto), nrRegCom, observatii, simbolBanca+contBanca (→ TRA-IBAN), scadentaImplicita, flagPF, emailSediu, codExtern, tvaIncasare, flagProducator.
Prerequisite: POST /api/config/id-part-field cu fieldName=CodExtern pentru a folosi cod extern ca identificator.

PUT /api/parteneri/update — ModificaPartener

Modifică un partener existent. Aceleași câmpuri ca AdaugaPartener. id identifică partenerul de modificat.

✅ Testat 14 mai 2026 — 2 runde de modificări: (1) localitate, adresă, telefon, email, observații, nrRegCom, persoaneContact; (2) simbolClasa=*SC, idAgent=3, simbolBanca=TRA+contBanca=IBAN, scadentaImplicita=30, flagPF=PJ, tvaIncasare=NU, flagProducator=NU. Toate reflectate corect în GetListaParteneri.

Exemplu request

PUT /api/parteneri/update
{
  "id": "TESTAPI001",
  "denumire": "TEST API PARTENER SRL",
  "codFiscal": "RO99999999",
  "localitate": "ORADEA",
  "adresa": "Str. Modificata nr. 99",
  "telefon": "0711111111",
  "codExtern": "TESTAPI001",
  "emailSediu": "test@testapi.ro",
  "observatii": "Partener de test API",
  "nrRegCom": "J05/999/2026",
  "persoaneContact": "Ion Popescu"
}

Răspuns

{"success": true, "data": {"method": "ModificaPartener", "result": 1}}
