Import Modificări Preț — POST /api/import/modificari-pret

VALIDATE OK

Importă modificări de preț de vânzare pe gestiune cu document contabil (generează diferențe de preț în contabilitate). Flow: SetDocsData → ModifPretValide → ImportaModifPret.

✅ Validate OK 14 mai 2026 — format dedus prin 7 iterații de erori. Nu s-a importat efectiv (ar schimba prețuri pe firma reală). Tipdocument=MODIFICARE PRET, secțiune [PV_1], gestiune per item.
Diferență față de ModiProduct: PUT /api/produse/update schimbă prețul din nomenclator fără document contabil. Import modificări preț generează document justificativ cu efect contabil (cont 378 diferențe de preț).

Request body

POST /api/import/modificari-pret
{
  "lines": [
    "[InfoPachet]",
    "AnLucru=2026",
    "LunaLucru=5",
    "Tipdocument=MODIFICARE PRET",
    "TotalModifPret=1",
    "Logon=Master",
    "",
    "[PV_1]",
    "Operatie=A",
    "NrDoc=99999",
    "Data=14.05.2026",
    "TotalArticole=1",
    "",
    "[Items_1]",
    "Item_1=9007912539582;Buc;69;2.50;MP;"
  ]
}

Secțiunea [InfoPachet]

CâmpObligatoriuFormatDescriere
TipdocumentDAstringFix: MODIFICARE PRET (NU "MODIFICARI DE PRET"!)
TotalModifPretDAintegerNumăr documente (NU TotalDocumente!)
AnLucru / LunaLucru / LogonDA-Standard

Secțiunea [PV_N]

Atenție: Secțiunea e [PV_1] (Process Verbal). NU [Document_1], [ModifPret_1] sau [Modificare_1]!
CâmpObligatoriuFormatVerificatDescriere
OperatieDAstring✅A = adăugare
NrDocDAinteger✅Număr document (proces verbal)
DataDAdd.mm.yyyy✅Data modificării de preț
TotalArticoleDAinteger✅Nr. linii items

Secțiunea [Items_N]

Format: Item_N=CodArticol;UM;Cantitate;PretNou;Gestiune;

CâmpPozObligatoriuVerificatDescriere
CodArticol1DA✅SKU/EAN (depinde de SetIDArtField)
UM2DA✅Unitate măsură
Cantitate3DA✅Cantitate pe stoc (la care se aplică noul preț)
PretNou4DA✅Noul preț de vânzare
Gestiune5DA✅Simbol gestiune (eroare 301 dacă invalid)

Erori posibile

CodMesajCauză
131Nu pare a fi MODIFICARI DE PRETTipdocument sau TotalModifPret greșit
105Nu gasesc referinte despre documentulSecțiunea nu e [PV_N]
301Nu gasesc gestiuneaGestiune invalidă pe item
