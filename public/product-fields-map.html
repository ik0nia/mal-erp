① Povestea datelor

Totul pleacă de la woo_products. Fiecare rând este un produs vândut pe site. Câmpul sku este liantul universal — același cod apare în WinMentor, în WooCommerce și la furnizori. Produsul poartă cu el prețul curent de vânzare, starea stocului, clasificarea ABC/XYZ și parametrii de reaprovizionare. Toate celelalte tabele gravitează în jurul lui.

Unde se află fizic marfa? Un produs poate fi în mai multe depozite simultan. product_stocks are câte un rând per produs × locație, actualizat la fiecare 5 minute de WinMentor Bridge. Câmpul sell_price din acest tabel este sursa de adevăr pentru prețul de vânzare în timp real — nu WooCommerce, nu un câmp manual, ci ultima valoare confirmată de Bridge.

Cum arată evoluția stocului în timp? De fiecare dată când Bridge citește stocul, actualizează daily_stock_metrics: stoc minim intra-zi, maxim, variație față de ziua anterioară. La 17:30 se face un snapshot de închidere zilnică. Aceste date alimentează graficele BI și rapoartele săptămânale și lunare trimise automat.

De unde vine marfa? product_suppliers leagă fiecare produs de furnizorii săi, cu toate condițiile comerciale negociate: lead time, MOQ, SKU furnizor. Un produs poate fi aprovizionat de la mai mulți furnizori, dar is_preferred = true marchează cel ales implicit la generarea comenzii. Pentru fiecare pereche produs-furnizor există N trepte cantitative în product_supplier_price_breaks — 1–9 buc = preț X, 10–49 = preț Y, 50+ = preț Z — cu posibilitate de valabilitate sezonieră.

Ce prețuri oferă furnizorii prin email? Sistemul procesează automat emailurile primite. Când AI detectează un preț, îl salvează în supplier_price_quotes cu referință la emailul sursă prin email_message_id. Un buyer poate compara oricând ofertele primite cu condițiile din contractul actual.

Cum s-a schimbat prețul de vânzare în timp? Orice modificare de preț de vânzare generează o linie în product_price_logs: old_price → new_price, sursa, timestamp. Iar orice recepție de marfă din WinMentor generează o linie în product_purchase_price_logs cu prețul de achiziție EUR și RON, cursul zilei și firma. Împreună, cele două tabele permit calculul marjei reale pentru orice perioadă din trecut.

Ce se întâmplă când prețul sare brusc? La procesarea fiecărei intrări WinMentor, sistemul compară prețul nou cu media ultimelor 90 de zile. Dacă variația depășește pragul (ex: +30%), se creează automat o înregistrare în winmentor_price_anomalies de tip price_spike, price_drop, supplier_change sau possible_sku_reuse. Buyer-ul primește notificare, analizează și marchează reviewed = true.

Cum se generează o comandă la furnizor? Din cererile interne (PNR-uri) se creează un Purchase Order. Fiecare linie din PO este o înregistrare în purchase_order_items cu un snapshot al numelui și SKU-ului la momentul comenzii. Câmpul sources_json reține exact ce cereri interne au generat linia — traseabilitate completă. La recepție se completează received_quantity și, dacă există discrepanță, received_note cu motivul.

Categorii și oferte client. woo_categories este ierarhic (parent recursiv) și legat de produse printr-o relație N:N — un produs poate fi în mai multe categorii simultan. offer_items sunt liniile ofertelor comerciale generate pentru clienți: snapshot complet (name, SKU, preț, discount) pentru a garanta că oferta nu se modifică dacă produsul e redenumit ulterior. line_total = qty × unit_price × (1 − discount%), calculat automat.

① Creare produs (WooCommerce sync)

SyncProductsJob {
  // Woo API → woo_products
  woo_id, sku, name, slug, status
  regular_price, sale_price, price
  stock_status, product_type
  description, weight, dimensions
  data = { permalink, attributes }
  source = 'woocommerce'
}

② Sincronizare stoc (WinMentor Bridge)

SyncStockFromBridgeJob {
  // Bridge → product_stocks
  quantity per location_id
  source = 'winmentor'
  → woo_products.stock_status
}
SyncToyaPricesJob {
  // Toya feed (delta only)
  IF price Δ → regular_price → Woo
             → product_price_logs
  IF stock Δ → stock_status → Woo
}

ProcessWinmentorIntrariCmd {
  // winmentor_intrari_raw → logs
  IF supplier.default_currency=EUR:
    price × BNR_rate → RON
    currency='EUR', exchange_rate=BNR
  ELSE: currency='RON'
  → product_purchase_price_logs
  → product_suppliers.last_purchase_price
  detectAnomaly():
    IF Δ% > prag:
      → winmentor_price_anomalies
}
