WinMentor este un sistem contabil închis, accesibil doar printr-un DLL COM, fără API web. MentorAPI îl transformă într-o platformă deschisă: un strat REST/JSON modern prin care orice aplicație (magazin online, app mobilă, BI, alt ERP) poate citi și scrie în WinMentor prin HTTP standard. Produs matur, testat end-to-end și deja în producție.

Inclus în platforma ERP Malinco: clienții care folosesc platforma ERP au integrarea WinMentor API inclusă în abonament, fără cost suplimentar (valoare echivalentă ~100 €/lună). Oferta de mai jos se adresează firmelor care doresc doar WinMentor API, ca produs de sine stătător.
Ce include
195 endpoint-uri REST (111 GET / 80 POST / 4 PUT), autentificare API-Key, paginare, JSON normalizat
Citire: stocuri (multiple variante), vânzări, facturi intrare/ieșire, recepții/NIR, transferuri, comenzi, parteneri, articole, solduri
Import structurat (8 tipuri document): comenzi furnizori/client, facturi intrare/ieșire, transferuri, bonuri consum, modificări preț, reglare inventar — cu validate/import/preview
Scriere master-data: adăugare/modificare parteneri (35 câmpuri), produse/articole, gestiuni, clase
Sync stoc + prețuri: motorul real care alimentează un magazin WooCommerce în producție
Documentație completă: OpenAPI 3 (100 operațiuni, 89 scheme), Swagger UI live, pagină de audit cu exemple curl
