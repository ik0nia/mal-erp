WinMentor Bridge — API Reference

Documentatie tehnica completa pentru toate endpoint-urile HTTP/JSON expuse de WinMentor Bridge v1.2.
Generat din documentatia oficiala + reverse engineering empiric (Aprilie 2026).

v1.2 — Martie 2026 90+ endpoint-uri DocImpServer COM

A Autentificare

Toate endpoint-urile (exceptie: /api/health si /api/diagnostics) necesita API Key transmis prin:

Header:  X-API-Key: cheia-voastra
Query:   ?api_key=cheia-voastra
Nota API Key-ul se gaseste in appsettings.json si se auto-genereaza la prima pornire (doar litere si cifre, fara caractere speciale).

B Format Raspuns Standard

Raspuns succes
{
  "success": true,
  "data": { ... } | [ ... ] | "string",
  "errors": [],
  "timestamp": "2026-03-08T12:00:00Z"
}
Raspuns eroare
{
  "success": false,
  "data": null,
  "errors": ["Mesaj eroare 1", "Mesaj eroare 2"],
  "timestamp": "2026-03-08T12:00:00Z"
}
Raspuns raw (string[][])
{
  "success": true,
  "data": [
    ["camp1", "camp2", "camp3"],
    ["camp1", "camp2", "camp3"]
  ]
}

C Prerequisite — Firma & Luna

ObligatoriuMajoritatea endpoint-urilor necesita selectarea prealabila a firmei si lunii contabile. La reconectare COM (idle timeout, crash), Bridge-ul reaplica automat ultima firma/luna.
Flux obligatoriu inainte de orice operatie pe date
// Pas 1: Selecteaza firma + luna
POST /api/firme/select
{ "firma": "NUMEFIRMA SRL", "an": 2026, "luna": 3 }

// Pas 2 (doar pentru operatii cu parteneri/producatori):
POST /api/config/id-part-field
{ "fieldName": "CodExtern" }   // sau CodIntern / CodFiscal

// Pas 3 (optional, pentru identificare articole):
POST /api/config/id-art-field
{ "fieldName": "CodExtern" }   // sau CodIntern

1 Health & Diagnosticare

GET /api/health Fara autentificare

Verifica starea serviciului. Nu necesita autentificare.

// Raspuns
{ "success": true, "data": {
    "status": "running",
    "instanceId": "a3f7b2c1-4d5e-...",
    "comConnected": false,
    "timestamp": "2026-03-08T12:00:00Z"
}}
NotacomConnected este false pana la primul request care necesita COM (conexiunea e lazy).
GET /api/diagnostics

Diagnosticare COM — verifica daca ProgID-ul DocImpServer.DocImpObject este inregistrat in Windows Registry. Fara autentificare.

GET /api/versiuni

Returneaza versiunile WinMentor si DocImpServer. Necesita firma selectata.

{ "success": true, "data": { "verMentor": 16.43, "verServer": 1.87 }}
GET /api/erori

Returneaza lista erorilor din sesiunea COM curenta (buffer intern GetListaErori). Util dupa un import esuat.

{ "success": true, "data": ["Eroare 1", "Eroare 2"] }

5a AddProduct — POST /api/produse/add

Prerequisite obligatoriu Inainte de AddProduct, setati id-part-field pe CodIntern.
AddProduct foloseste MEREU marca CodIntern a producatorului, indiferent de setarea globala.
POST /api/produse/add

Adauga un produs nou in nomenclatorul WinMentor. Parametrul info = string cu 19 campuri separate prin ;.

Surse folosite pentru campuri Campurile au fost identificate din 4 surse complementare:
[RE] = Reverse engineering pe 2DocImpCl.exe + testare empirica (validat functional)
[NA] = NomenclatorArticol — structura Go libWMEdcom types.go (pozitii confirmate din GetNomenclatorArticole)
[AN] = Articole noi.pdf — documentatie oficiala WinMentor (format key=value, alt mecanism de import)
[?] = Necunoscut / neconfirmat

Format campuri InfoProdus (19 pozitii)

0CodExternDaCod extern articol — identificator unic (EAN, cod bare). [RE][NA]
1DenumireDaDenumirea produsului. [RE][NA][AN]
2DenUM ?NuPosibil DenUM (unitate masura denumire) — NA are DenUM la poz 2. Lasati gol daca nu stiti. [NA]
3IDProducatorNuMarca CodIntern a partenerului producator. 0 = fara producator. Necesita SetIDPartField(CodIntern). ATENTIE: NA are PretVanzare la poz 3 — structurile difera (NA returneaza date denormalizate). [RE]
4UMDaSimbolul unitatii de masura (Buc, kg, m, l, ml etc.). ATENTIE: NA are SimbolClasa la poz 4 — structurile difera. [RE][AN]
5TipSerieNuTipul de serie. RE: 0=fara, 1=cu serie. AN: 1=fara serie, 2=serie pe bucata, 3=serie pe lot. [RE][AN]
6CotaTVADaProcentul TVA: 0, 5, 9, 19, 21 (standard actual = 21). Validat empiric la aceasta pozitie. NOTA: NA are CotaTVA la poz 10, nu 6. [RE]
7TVAInclus ?NuPosibil TVAInclus (D/N) — prezent in AN. NA are DenProducator la poz 7. Lasati gol. [AN][?]
8GestiuneImplicita ?NuPosibil simbolul gestiunii implicite — NA are GestImplicita la poz 8, AN o are ca si camp. Lasati gol daca nu specificati. [NA][AN][?]
9CodExternAltNuCod extern alternativ — de obicei acelasi cu poz 0. NA: CodExternUnic la poz 9 (acelasi concept). [RE][NA]
10DenUMSecundara ?NuPosibil unitate de masura secundara — NA are DenUMSecundara la poz 11, AN o mentioneza. Lasati gol. [NA][?]
11ParitateUMSecundara ?NuPosibil paritatea intre UM primara si secundara — NA: ParitateUMSecundara la poz 12. Lasati gol. [NA][?]
12SimbolClasa ?NuPosibil simbolul clasei de articole — AN: Clasa, NA: SimbolClasa la poz 4. Pozitia exacta neconfirmata. Lasati gol. [AN][?]
13MasaNuGreutate/masa in kg (ex: 0.4). NA confirma Masa la poz 13. [RE][NA][AN]
14Serviciu ?NuPosibil flag Serviciu (D/N) — NA: Serviciu la poz 14, AN: Serviciu=D/N. Lasati gol. [NA][AN][?]
15CodVamal ?NuPosibil codul vamal — NA: CodVamal la poz 15, AN: CodVamal prezent. Lasati gol. [NA][AN][?]
16PretMinim ?NuPosibil pretul minim de vanzare — NA: PretMinim la poz 16, AN: prezent. Lasati gol. [NA][AN][?]
17CantImplicita ?NuPosibil cantitatea implicita — NA: CantImplicita la poz 17, AN: prezent. Lasati gol. [NA][AN][?]
18Flag / PretValuta ?NuRE: D = flag activ. NA: PretValuta la poz 18. Conflict nerezolvat intre surse. [RE][NA][?]

Campuri suplimentare identificate din Articole noi.pdf (nelocalizate pozitional)

5b ModiProduct — PUT /api/produse/update

Format DIFERIT de AddProduct Ordinea campurilor este diferita! Campurile goale nu se modifica — doar cele completate se actualizeaza.
PUT /api/produse/update

Modifica un produs existent. Produsul e identificat prin CodExtern (pozitia 0). Campurile goale nu se modifica.

Format campuri InfoProdus ModiProduct

0CodExternDaIdentifica produsul de modificat
1IDProducatorNuID producator. Respecta SetIDPartField (CodExtern/CodIntern/CodFiscal). Gol = nu modifica
2SimbolClasaNuSimbol clasa articol. Gol = nu modifica
3PretVanzareNuPret fara TVA. Recalculeaza automat PretVCuTVA. Gol = nu modifica
4(necunoscut)NuNu are efect vizibil
5(necunoscut)NuNu are efect vizibil
6DenumireNuDenumirea produsului. Gol = nu modifica
7+(restul)NuNu au efect vizibil

R4 Instalare & Configurare

Cerinte sistem

CerintaDetalii
Sistem operareWindows 10/11 sau Windows Server 2016+
WinMentor ClassicInstalat si functional pe acelasi server
DocImpServerInregistrat in Windows Registry (se instaleaza cu WinMentor)
Spatiu disc~100 MB pentru executabil
RAMMinim 256 MB disponibil
Porturi8500 (HTTP) si 8501 (HTTPS) — configurabile
.NET RuntimeNU este necesar (inclus in executabil)

appsettings.json — Parametri

{
  "WinMentorBridge": {
    "Port": 8500,               // Portul HTTP
    "HttpsPort": 8501,          // Portul HTTPS (null = dezactivat)
    "BindAddress": "0.0.0.0",   // IP ascultare (127.0.0.1 = doar local)
    "MaxConcurrentConnections": null,   // null = nelimitat
    "InstanceId": null,         // Auto-generat la prima pornire
    "ApiKey": "CHANGE-ME-ON-FIRST-RUN",
    "CentralPlatformUrl": null, // URL platforma web centrala (push sync)
    "ComProgId": "DocImpServer.DocImpObject",
    "ComIdleTimeoutSeconds": 300,  // Disconnect COM dupa 5 min inactivitate
    "CacheDurationMinutes": 5,     // 0 = dezactivat
    "Ssl": {
      "CertificatePath": null,     // null = self-signed auto
      "CertificatePassword": null
    }
  }
}

Instalare ca Windows Service

// Instalare
sc create WinMentorBridge binPath="C:\WinMENT\WinMentorBridge\WinMentorBridge.exe" start=auto

Troubleshooting

EroareCauza & Solutie
"API key not configured"appsettings.json nu a fost gasit sau contine valoarea default. Verificati ca fisierul e in acelasi folder cu executabilul.
"DocImpServer is not connected"ProgID-ul COM nu e in Registry. Accesati /api/diagnostics pentru detalii.
"The RPC server is unavailable"DocImpServer a cazut. Aplicatia se reconecteaza automat la urmatorul request.
Raspunsuri lenteNormal la prima cerere (COM nu suporta paginare nativa). Folositi cache-ul si paginarea.
Port ocupatSchimbati Port si/sau HttpsPort in appsettings.json.
