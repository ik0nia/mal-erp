Prerequisite
Inainte de a apela AddProduct sau ModiProduct, trebuie:
1. Selectata firma si luna: POST /api/firme/select
2. Setat campul de identificare parteneri (pentru producator):
POST /api/config/id-part-field
{ "fieldName": "CodIntern" }    // pentru AddProduct

POST /api/config/id-part-field
{ "fieldName": "CodExtern" }    // pentru ModiProduct
ATENTIE: AddProduct si ModiProduct folosesc ID-uri de producator DIFERITE!
AddProduct foloseste MEREU marca CodIntern a partenerului (indiferent de SetIDPartField, dar trebuie setat pe CodIntern).
ModiProduct respecta SetIDPartField — deci daca setati CodExtern, va folosi CodExtern-ul partenerului.

Cote TVA valide
Campul Cota TVA accepta doar cotele definite in baza de date WinMentor. Valorile valide sunt procentele reale:
Alte valori (1, 2, 3, 4, 8, 10, etc.) genereaza eroarea 435: Cota de TVA inexistenta in baza de date.


AddProduct (POST /api/produse/add)
Adauga un produs nou in nomenclatorul WinMentor. Parametrul info este un string cu 19 campuri separate prin ";" (semicolon).

Format campuri InfoProdus (19 pozitii)

Exemplu complet (cu producator)
// Prerequisite:
POST /api/config/id-part-field
{ "fieldName": "CodIntern" }

// AddProduct:
POST /api/produse/add
Content-Type: application/json

{
  "info": "EAN123456;Guma Tatoo 20gr;;728025591;Buc;1;9;;;EAN123456;;;;;0.4;;;;;D"
}
Unde:
- EAN123456 = cod extern articol (pozitia 0 si 9)
- 728025591 = marca CodIntern a partenerului producator (pozitia 3)
- Buc = unitate masura (pozitia 4)
- 1 = tip serie (pozitia 5)
- 9 = cota TVA 9% (pozitia 6)
- 0.4 = masa in kg (pozitia 13)
- D = flag activ (pozitia 18)

Exemplu minim (fara producator)
POST /api/produse/add
{
  "info": "CODTEST;Produs Simplu;;0;Buc;0;20;;;CODTEST;;;;;;;;;;"
}
Doar campurile obligatorii: cod, denumire, UM si cota TVA. Producator = 0 (fara).

Raspuns
{ "success": true, "data": { "result": 1, "message": "Produs adaugat" } }

ModiProduct (PUT /api/produse/update)
Modifica un produs existent. Are un format DIFERIT de AddProduct. Campurile goale nu se modifica — doar cele completate se actualizeaza.

Format campuri InfoProdus (ModiProduct)
ATENTIE: Formatul ModiProduct este DIFERIT de AddProduct! Ordinea campurilor nu este aceeasi.

Exemplu: modifica mai multe campuri
// Prerequisite:
POST /api/config/id-part-field
{ "fieldName": "CodExtern" }

// ModiProduct:
PUT /api/produse/update
Content-Type: application/json

{
  "info": "ART001;43312030;;150;;;Denumire Noua;;;;;;;;;;;;"
}
Modifica producatorul (CodExtern 43312030), pretul (150) si denumirea. SimbolClasa ramane neschimbat (gol pe pozitia 2).

Exemplu: modifica doar pretul
PUT /api/produse/update
{
  "info": "ART001;;;99.50;;;;;;;;;;;;;;;;"
}

Exemplu: modifica doar denumirea
PUT /api/produse/update
{
  "info": "ART001;;;;;;Denumire Actualizata;;;;;;;;;;;;"
}

Raspuns
{ "success": true, "data": { "result": 1, "message": "Produs modificat" } }
