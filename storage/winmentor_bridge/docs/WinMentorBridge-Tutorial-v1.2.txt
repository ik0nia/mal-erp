WinMentor Bridge
Micro-Connector pentru WinMentor Classic
Ghid de Instalare, Configurare si Utilizare
Versiunea 1.2 - Martie 2026

Acest document descrie pasii necesari pentru instalarea si configurarea WinMentor Bridge pe serverul unde este instalat WinMentor Classic.

Cuprins

1. Prezentare Generala
WinMentor Bridge este un micro-connector care face legatura dintre WinMentor Classic (software de contabilitate desktop) si platforma web centrala.
Ce face:
Se conecteaza la DocImpServer (componenta COM a WinMentor) direct pe server
Expune datele din WinMentor prin HTTP/HTTPS API in format JSON
Functioneaza ca un singur fisier executabil - zero dependente externe
Poate rula ca aplicatie consola sau ca Windows Service
Genereaza automat API Key si Instance ID la prima pornire
Gestioneaza automat conexiunea COM (se conecteaza lazy, se deconecteaza dupa inactivitate)
Suporta paginare si cautare pe liste mari de date (ex: parteneri)
Cache in memorie pentru raspunsuri rapide la cereri repetate
Binding pe IP specific si limita de conexiuni simultane configurabile
Import documente (facturi, comenzi, incasari, transferuri, etc.)
CRUD pentru nomenclatoare (parteneri, produse, clase articole, gestiuni)
Peste 90 de endpoint-uri API care acopera intreaga functionalitate WinMentor COM

2. Cerinte de Sistem
IMPORTANT: Nu este necesara instalarea .NET pe server. Executabilul este self-contained si include tot ce are nevoie.

4. Configurare (appsettings.json)
La prima pornire, aplicatia genereaza automat InstanceId si ApiKey. Totusi, puteti configura manual inainte.
Structura completa a fisierului:
{
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft.AspNetCore": "Warning"
    }
  },
  "WinMentorBridge": {
    "Port": 8500,
    "HttpsPort": 8501,
    "BindAddress": "0.0.0.0",
    "MaxConcurrentConnections": null,
    "InstanceId": null,
    "ApiKey": "CHANGE-ME-ON-FIRST-RUN",
    "CentralPlatformUrl": null,
    "ComProgId": "DocImpServer.DocImpObject",
    "ComIdleTimeoutSeconds": 300,
    "CacheDurationMinutes": 5,
    "Ssl": {
      "CertificatePath": null,
      "CertificatePassword": null
    }
  }
}

IMPORTANT: Notati API Key-ul din consola! Acesta va fi necesar pentru toate cererile API.
Nota: API Key-ul contine doar litere (A-Z, a-z) si cifre (0-9), fara caractere speciale, pentru compatibilitate maxima cu URL-uri si headere HTTP.

Pentru oprire, apasati Ctrl+C in consola.

6. Testare cu Postman
In pachetul de livrare este inclus fisierul WinMentorBridge.postman_collection.json cu toate cele ~90 endpoint-uri pre-configurate. Importati-l in Postman si setati variabilele base_url si api_key.
Health Check (fara autentificare)
GET http://localhost:8500/api/health
Raspuns asteptat:
{
  "success": true,
  "data": {
    "status": "running",
    "instanceId": "a3f7b2c1-...",
    "comConnected": false,
    "timestamp": "2026-03-07T16:00:00Z"
  }
}
Nota: comConnected este false initial - conexiunea COM se deschide lazy la primul request care o necesita.
Lista firme (cu autentificare)
GET http://localhost:8500/api/firme
Header: X-API-Key: [cheia-voastra]
Selectare firma si luna contabila
POST http://localhost:8500/api/firme/select
Header: X-API-Key: [cheia-voastra]
Header: Content-Type: application/json
Body:
{
  "firma": "NUMEFIRMA",
  "an": 2026,
  "luna": 3
}
Lista parteneri (cu paginare)
GET http://localhost:8500/api/parteneri?page=1&pageSize=50
Header: X-API-Key: [cheia-voastra]
IMPORTANT: Inainte de a citi date, trebuie selectata firma si luna contabila cu /api/firme/select.

9. Paginare, Cautare si Cache
Paginare
Endpoint-urile /api/parteneri, /api/articole si /api/stocuri suporta paginare server-side.
Parametri:
Raspunsul include metadate de navigare: page, pageSize, totalItems, totalPages, hasNextPage, hasPreviousPage.
Cache in memorie
Prima cerere citeste datele din COM (poate dura cateva secunde). Cererile urmatoare se servesc din cache (instant). Cache-ul expira dupa CacheDurationMinutes (default: 5 minute) si se invalideaza automat la schimbarea firmei/lunii.

10. Securitate (HTTPS)
Certificat self-signed (implicit)
La prima pornire se genereaza automat un certificat self-signed valid 2 ani. In Postman, dezactivati verificarea SSL din Settings > SSL certificate verification.
Certificat propriu (productie)
"Ssl": {
  "CertificatePath": "certificate.pfx",
  "CertificatePassword": "parola-certificat"
}
Doar HTTP (dezactivare HTTPS)
"HttpsPort": null
Restrictionare acces
"BindAddress": "127.0.0.1"     // doar local
"BindAddress": "192.168.1.100"  // doar o interfata
"MaxConcurrentConnections": 50  // limita conexiuni

11. Depanare (Troubleshooting)
"API key not configured"
Cauza: appsettings.json nu a fost gasit sau contine valoarea default. Verificati ca fisierul se afla in acelasi folder cu executabilul.

"DocImpServer is not connected"
Cauza: ProgID-ul COM nu a fost gasit in Registry. Accesati /api/diagnostics pentru detalii.

"The RPC server is unavailable"
Cauza: DocImpServer a fost oprit sau a cazut. Aplicatia se reconecteaza automat la urmatorul request.

Conexiunea COM ramane deschisa
Aplicatia elibereaza automat conexiunea COM dupa ComIdleTimeoutSeconds (default: 300 secunde) de inactivitate.

Raspunsuri lente
COM-ul nu suporta paginare nativa. Folositi cache-ul si paginarea (?page=1&pageSize=100). Prima cerere dureaza cateva secunde, dar urmatoarele se servesc instant.

Port-ul este ocupat
Schimbati Port si/sau HttpsPort in appsettings.json cu valori disponibile.

12. Format Raspuns API
Toate endpoint-urile returneaza acelasi format standard:
{
  "success": true,
  "data": { ... },
  "errors": [],
  "timestamp": "2026-03-07T16:00:00Z"
}
In caz de eroare:
{
  "success": false,
  "data": null,
  "errors": ["Mesaj eroare 1", "Mesaj eroare 2"],
  "timestamp": "2026-03-07T16:00:00Z"
}
Endpoint-urile care returneaza date raw (fara model tipizat) returneaza un array de string[]:
{
  "success": true,
  "data": [
    ["camp1", "camp2", "camp3"],
    ["camp1", "camp2", "camp3"]
  ]
}
