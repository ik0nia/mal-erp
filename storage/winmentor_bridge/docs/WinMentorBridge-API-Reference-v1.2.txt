WinMentor Bridge
API Reference - Documentatie Tehnica Detaliata
Versiunea 1.2 - Martie 2026
Referinta completa pentru toate endpoint-urile API: parametri, tipuri de date, exemple cereri/raspunsuri.

Cuprins

1. Format General
Toate endpoint-urile returneaza acelasi format JSON standard:
{
  "success": true | false,
  "data": { ... } | null,
  "errors": ["msg1", "msg2"],
  "timestamp": "2026-03-08T12:00:00Z"
}
Campuri standard:

Autentificare:
Toate endpoint-urile (exceptie: /api/health) necesita API Key transmis in unul din urmatoarele moduri:
Header:  X-API-Key: cheia-voastra
Query:   ?api_key=cheia-voastra

Prerequisite: Firma si luna de lucru:
Majoritatea endpoint-urilor de date necesita selectarea prealabila a firmei si lunii contabile prin POST /api/firme/select. Daca conexiunea COM se reconecteaza (idle timeout, crash), Bridge-ul reaplica automat ultima firma/luna selectata.

2. Health & Diagnosticare
GET  /api/health
Verifica starea serviciului. Nu necesita autentificare.
Fara parametri.

Campuri raspuns (data):

Exemplu cerere:
GET http://localhost:8500/api/health

Exemplu raspuns:
{ "success": true, "data": {
    "status": "running",
    "instanceId": "a3f7b2c1-4d5e-...",
    "comConnected": true,
    "timestamp": "2026-03-08T12:00:00Z"
  }
}
Nota: comConnected este false pana la primul call care necesita COM.

GET  /api/diagnostics
Diagnosticare COM — verifica daca ProgID-ul este inregistrat in Windows Registry. Nu necesita autentificare.
Fara parametri.

Campuri raspuns (data):

Exemplu cerere:
GET http://localhost:8500/api/diagnostics

GET  /api/versiuni
Returneaza versiunile WinMentor si DocImpServer. Necesita firma selectata prealabil.
Fara parametri.

Campuri raspuns (data):

Exemplu cerere:
GET http://localhost:8500/api/versiuni

Exemplu raspuns:
{ "success": true, "data": {
    "verMentor": 16.43,
    "verServer": 1.87
  }
}
Returneaza 0 pentru ambele daca nu e selectata firma.

GET  /api/erori
Returneaza lista erorilor din sesiunea COM curenta (buffer-ul intern GetListaErori).
Fara parametri.

Exemplu cerere:
GET http://localhost:8500/api/erori

Exemplu raspuns:
{ "success": true, "data": ["Eroare 1", "Eroare 2"] }
Util dupa un import esuat pentru a vedea detaliile erorilor.


3. Configurare
POST  /api/config/id-part-field
Seteaza campul folosit ca identificator unic al partenerilor in operatiunile de import/export. Afecteaza modul in care WinMentor identifica un partener la import.
Parametri:

Campuri raspuns (data):

Exemplu cerere:
POST http://localhost:8500/api/config/id-part-field
Content-Type: application/json

{ "fieldName": "CodExtern" }

Exemplu raspuns:
{ "success": true, "data": { "field": "CodExtern", "applied": true } }
Implicit WinMentor foloseste CodIntern. Setati CodExtern daca sistemul extern are propriile coduri.

POST  /api/config/id-art-field
Seteaza campul folosit ca identificator unic al articolelor in operatiunile de import/export.
Parametri:

Campuri raspuns (data):

Exemplu cerere:
POST http://localhost:8500/api/config/id-art-field
Content-Type: application/json

{ "fieldName": "CodExtern" }

POST  /api/config/descarcare-automata
Seteaza flag-ul de descarcare automata a stocului la vanzare.
Parametri:

Exemplu cerere:
POST http://localhost:8500/api/config/descarcare-automata?flag=1

Exemplu raspuns:
{ "success": true, "data": { "flag": 1, "applied": true } }

GET  /api/config/constanta/{id}/{simbol}
Obtine o constanta de configurare din WinMentor dupa ID numeric si simbol.
Parametri:

Campuri raspuns (data):

Exemplu cerere:
GET http://localhost:8500/api/config/constanta/1/CURS_EUR
Constantele disponibile depind de configuratia WinMentor.


4. Firme
GET  /api/firme
Returneaza lista tuturor firmelor definite in WinMentor. Nu necesita firma selectata prealabil.
Fara parametri.

Campuri raspuns (data):

Exemplu cerere:
GET http://localhost:8500/api/firme

Exemplu raspuns:
{ "success": true, "data": [
    { "nume": "FIRMA DEMO SRL" },
    { "nume": "SC EXEMPLU SA" }
  ]
}

GET  /api/firme/{numeFirma}/luni
Returneaza lunile contabile disponibile pentru o firma. Nu necesita firma selectata prealabil.
Parametri:

Exemplu cerere:
GET http://localhost:8500/api/firme/FIRMA%20DEMO%20SRL/luni

Exemplu raspuns:
{ "success": true, "data": ["2025_01", "2025_02", ..., "2026_03"] }
Numele firmei trebuie URL-encoded daca contine spatii.

POST  /api/firme/select
Selecteaza firma si luna de lucru. OBLIGATORIU inainte de orice operatiune pe date. Invalideaza automat cache-ul de parteneri si articole. Starea este persistata in memorie si reaplicata automat la reconectare COM.
Parametri:

Campuri raspuns (data):

Exemplu cerere:
POST http://localhost:8500/api/firme/select
Content-Type: application/json

{ "firma": "FIRMA DEMO SRL", "an": 2026, "luna": 3 }

Exemplu raspuns:
{ "success": true, "data": {
    "firma": "FIRMA DEMO SRL",
    "an": 2026, "luna": 3
  }
}
Dupa selectare, toate endpoint-urile de date opereaza pe aceasta firma/luna.
La reconectare COM (dupa idle timeout sau crash), Bridge-ul reaplica automat ultima firma/luna.


5. Parteneri
GET  /api/parteneri
Returneaza lista partenerilor cu suport de paginare, cautare si cache. Datele sunt incarcate o singura data din COM si servite paginat din memorie.
Parametri:

Campuri raspuns (data):

Exemplu cerere:
GET http://localhost:8500/api/parteneri?page=1&pageSize=50&search=SRL

Exemplu raspuns:
{ "success": true, "data": {
    "items": [{ "idPartener": "1", "denumire": "DEMO SRL", ... }],
    "page": 1, "pageSize": 50,
    "totalItems": 342, "totalPages": 7,
    "hasNextPage": true, "hasPreviousPage": false
  }
}
Campurile string[] (sedii) sunt multi-valori din campuri COM separate cu "~".
Cache-ul se invalideaza automat la POST /api/firme/select.

GET  /api/parteneri/{partId}/info
Returneaza informatiile complete ale unui singur partener dupa ID. Raspunsul este un string cu campuri separate de ";".
Parametri:

Exemplu cerere:
GET http://localhost:8500/api/parteneri/P001/info

Exemplu raspuns:
{ "success": true, "data": "P001;DEMO SRL;RO12345678;..." }
Campurile din string depind de configurarea WinMentor.

POST  /api/parteneri/add
Adauga un partener nou in nomenclatorul WinMentor. Informatiile se trimit ca string cu campuri separate de ";" (35 campuri).
Parametri:

Campuri raspuns (data):

Exemplu cerere:
POST http://localhost:8500/api/parteneri/add
Content-Type: application/json

{ "info": "P999;FIRMA NOUA SRL;RO99999999;Bucuresti;Str X nr 1;0212345678;Ion Popescu;...restul campurilor..." }
Invalideaza automat cache-ul de parteneri.
Campurile exacte si ordinea lor sunt documentate in proiectul Delphi sample al WinMentor.

PUT  /api/parteneri/update
Modifica un partener existent. Partenerul este identificat dupa campul configurat cu SetIDPartField.
Parametri:

Campuri raspuns (data):

Exemplu cerere:
PUT http://localhost:8500/api/parteneri/update
Content-Type: application/json

{ "info": "P001;FIRMA ACTUALIZATA SRL;RO12345678;..." }

GET  /api/parteneri/next-id
Returneaza urmatorul ID disponibil pentru un partener nou.
Fara parametri.

Exemplu cerere:
GET http://localhost:8500/api/parteneri/next-id

Exemplu raspuns:
{ "success": true, "data": "1543" }

POST  /api/parteneri/gen-cod
Genereaza coduri interne/externe/fiscale pentru parteneri care nu au.
Fara parametri.

Campuri raspuns (data):

Exemplu cerere:
POST http://localhost:8500/api/parteneri/gen-cod

14. Import Documente
Pipeline-ul de import este: SetDocsData(linii) > *Valide() > Importa*(). Endpoint-ul /api/import/{docType} executa toti pasii automat.

POST  /api/import/{docType}
Importa documente in WinMentor. Trimite liniile de date, le valideaza si optional le importeaza.
Parametri:

Campuri raspuns (data):

Exemplu cerere:
POST http://localhost:8500/api/import/facturi-iesire
Content-Type: application/json

{
  "lines": [
    "linia1;camp1;camp2;camp3;...",
    "linia2;camp1;camp2;camp3;..."
  ]
}

Exemplu raspuns:
{ "success": true, "data": {
    "isValid": true,
    "importedCount": 2,
    "errors": [],
    "warnings": ["Avertisment optional"]
  }
}
Formatul exact al liniilor (campuri, ordine) depinde de tipul documentului si este documentat in proiectul Delphi sample al WinMentor.
Daca validateOnly=true, se returneaza doar validarea fara import efectiv. Util pentru pre-verificare.

Tipuri de documente disponibile (docType):

GET  /api/import/doc-types
Returneaza lista tipurilor de documente disponibile pentru import.
Fara parametri.

Exemplu cerere:
GET http://localhost:8500/api/import/doc-types

Exemplu raspuns:
{ "success": true, "data": {
    "facturi-iesire": "Facturi iesire (vanzare)",
    "facturi-intrare": "Facturi intrare (NIR)",
    "comenzi": "Comenzi interne",
    ...
  }
}
